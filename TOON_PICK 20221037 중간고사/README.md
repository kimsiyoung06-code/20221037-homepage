# TOON PICK v2

## 포함된 기능
- 네이버 웹툰 / 카카오웹툰 플랫폼 필터
- 6개 장르별 탐색과 제목/작가 검색
- 60개 예시 작품(각 장르 10개 이상으로 장르 중복 포함)
- API 데이터 가져오기 버튼: 공개 커뮤니티 API에 연결을 시도하고, 실패 시 샘플 데이터 유지
- API에서 썸네일 URL이 제공될 경우 표지에 표시, 그렇지 않으면 CSS 기반 임시 커버
- 찜하기(localStorage), 취향 테스트, 소셜 링크 footer
- 회원가입 페이지 `signup.html` (데모: 이메일/닉네임만 브라우저 저장)
- 반응형 화면

## 실행
1. ZIP을 압축 해제
2. VS Code에서 `toon_pick_v2` 폴더 열기
3. VS Code의 Live Server 확장을 설치
4. `index.html`에서 우클릭 → Open with Live Server

## API 관련
- 이 프로젝트는 공개 커뮤니티 프로젝트 `HyeokjaeLee/korea-webtoon-api`의 서버에 연결을 시도합니다. 공식 네이버/카카오 웹툰 API가 아닙니다.
- API 서버의 라우트, CORS 정책, 가용성은 바뀔 수 있습니다. 메인 화면에서 `API 데이터 불러오기`를 눌러 확인하세요.
- API 연결이 안 되면 샘플 데이터가 표시됩니다. 현재 API 응답 구조를 확인하지 못하는 경우 자동 매핑이 안 될 수 있으니, API 문서(Swagger)에서 실제 엔드포인트와 필드명을 확인해 `app.js`의 `loadApi()` 및 `normApiItem()`을 조정해야 합니다.
- API가 제공하는 이미지 URL은 출처/사용 조건을 확인하고 사용하세요. 작품 에피소드 이미지나 불법 복제 콘텐츠는 포함하지 않습니다.

## 회원가입 주의
`signup.html`은 UI/폼 검사용입니다. 비밀번호는 저장하지 않으며 계정도 브라우저 로컬에만 등록합니다. 실제 서비스라면 Supabase Auth, Firebase Auth 또는 자체 서버 인증을 사용하세요. 실제 비밀번호를 입력하지 마세요.

## 소셜 링크
Footer 링크는 각 서비스의 일반 홈으로 연결되어 있습니다. 프로젝트의 실제 SNS 계정이 있다면 `index.html` 하단 링크 URL을 해당 계정 URL로 바꾸세요.
