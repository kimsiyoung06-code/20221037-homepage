# TOON PICK — 전체 프로젝트

## 실행 방법
1. 이 폴더를 압축 해제합니다.
2. VS Code에서 `TOON_PICK_FULL` 폴더를 엽니다.
3. Live Server 확장 프로그램을 설치합니다.
4. `index.html`을 우클릭한 뒤 **Open with Live Server**를 선택합니다.

## 포함 파일
- `index.html`: 메인 웹툰 탐색 페이지
- `style.css`: 전체 디자인 및 반응형 레이아웃
- `catalogue.js`: API 실패 시 표시할 샘플 웹툰 목록
- `app.js`: 검색, 플랫폼/장르 필터, 찜하기, 취향 테스트, API 연결
- `signup.html`: 회원가입 데모 페이지
- `signup.js`: 데모 회원가입 폼 검증
- `api/webtoons.js`: Vercel 서버리스 API 프록시

## API 연결 안내 (CORS 프록시)
- `api/webtoons.js`: Vercel 서버리스 함수가 원본 API를 서버 측에서 호출합니다. 브라우저에서 원본 API를 직접 호출하지 않으므로 브라우저 CORS 제한을 피할 수 있습니다.
- `app.js`: 같은 도메인의 `/api/webtoons` 엔드포인트를 호출합니다.
- GitHub에 전체 폴더를 올린 뒤 Vercel에서 해당 저장소를 Import/Deploy 하세요. Vercel에 배포한 주소에서 동작합니다.
- Live Server로 로컬에서 열면 `/api/webtoons` 서버리스 함수가 실행되지 않습니다. API 테스트는 Vercel 배포 URL에서 하세요.
- 이 프록시는 공개 커뮤니티 API `https://korea-webtoon-api-cc7dda2f0d77.herokuapp.com`를 사용합니다. 원본 서버가 중단됐거나 경로/응답 형식이 바뀐 경우 CORS와 무관하게 연결되지 않을 수 있습니다. 실패하면 샘플 목록은 계속 표시됩니다.

## 회원가입 안내
회원가입은 프런트엔드 데모입니다. 계정 정보 일부가 현재 브라우저의 `localStorage`에 저장되지만 비밀번호는 저장하지 않습니다. 서버 인증/DB가 없으므로 실제 비밀번호를 입력하지 마세요.


## API 연결 안내 (중요)

- 사이트는 `/api/webtoons` Vercel 서버리스 함수를 통해 데이터를 요청합니다.
- 먼저 기존 korea-webtoon-api를 시도하고, 원본 API가 응답하지 않으면 대체 공개 API에서 실제 네이버 웹툰 목록을 불러옵니다.
- 대체 API는 네이버 웹툰만 제공하므로 카카오 웹툰은 원본 API가 복구되지 않으면 실시간 목록에 포함되지 않습니다.
- Vercel에 배포한 뒤 `https://내-프로젝트.vercel.app/api/webtoons`를 직접 열어 JSON 데이터가 나오는지 확인할 수 있습니다.
- 공개 API는 제3자가 운영하므로 언제든 변경/중단될 수 있습니다.


### 이미지가 표시되지 않을 때

이 버전은 네이버 썸네일 이미지를 `/api/image` 프록시로 전달합니다. Vercel에 배포한 뒤 사이트를 열어 확인하세요. 로컬 파일을 더블클릭하거나 Live Server에서 열면 Vercel 함수가 실행되지 않으므로 이미지 프록시가 작동하지 않습니다.


## 추가된 기능
- `board.html`: 작품 추천/감상 후기/자유 이야기/스포일러 게시판
- 글 작성, 카테고리 필터, 검색, 좋아요, 글 삭제 (브라우저 localStorage 데모)
- 메인 페이지 커뮤니티 홍보 섹션과 추가 바로가기 카드
- 스크롤을 내리면 나타나는 맨 위로 버튼
- 게시판은 `style.css`와 `board.js`를 사용하며 별도 서버 없이 Live Server에서 실행 가능

주의: 게시판 글은 현재 브라우저에만 저장됩니다. 여러 사용자가 함께 쓰는 실제 게시판은 서버와 데이터베이스가 필요합니다.


## 이번 확장 업데이트
- 오늘의 웹툰 추첨: 무작위 작품 추천, 장르 랜덤 추첨, 다시 뽑기, 공식 플랫폼 링크, 찜하기
- 생성형 앰비언트 BGM 플레이어: 재생/일시정지와 음량 조절 지원. 외부 음악 파일 없이 브라우저 Web Audio로 재생합니다.
- 추첨 결과는 현재 웹툰 목록을 기준으로 생성되며, API 연결에 성공하면 API에서 불러온 목록도 추첨 대상이 됩니다.
- 브라우저 자동 재생 제한 때문에 BGM은 사용자가 재생 버튼을 직접 눌러야 시작됩니다.


### 추가된 추첨 편의 기능
- 다시 뽑기 시 직전 작품은 가능한 한 제외해 중복을 줄입니다.
- 장르 랜덤 재추첨, 추천 링크 복사, 찜 목록 저장을 지원합니다.
- 최근 추첨 결과 최대 5개를 브라우저에 저장하고 다시 열 수 있으며, 기록 전체 삭제도 가능합니다.


### 이번 추가 업데이트
- **기분별 추천**: 스트레스 해소, 설렘, 힐링, 긴장감, 판타지, 웃음 등 6가지 기분을 고르면 해당 장르로 이동합니다.
- **다크 모드**: 화면 모드를 바꾸면 브라우저에 선택이 저장됩니다.
- **찜 목록 내보내기**: 찜한 작품을 UTF-8 텍스트 파일로 백업할 수 있습니다.
- 위 기능은 외부 서버 없이 브라우저에서 작동합니다.
